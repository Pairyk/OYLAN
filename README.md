# OYLAN — исходный код

Это полный исходный код текущего прототипа OYLAN: React + TypeScript, Vinext/Vite.

## Запуск на компьютере

1. Установите Node.js версии 22.13 или новее и откройте папку проекта в VS Code.
2. В терминале установите зависимости и запустите сайт:

```sh
npm install
npm run dev
```

Откройте адрес, который появится в терминале.
Если используете pnpm, можно выполнить `pnpm install` и `pnpm dev`: в архиве есть pnpm-lock.yaml.

## Где редактировать

- app/page.tsx — экраны, методики, конструктор и прохождение.
- app/globals.css — оформление, в конце файла актуальная тема.
- app/learn-articles.ts — полные тексты статей.
- app/layout.tsx — язык страницы и метаданные.
- public/ — изображения и значки.

Ответы ИИ демонстрационные: API-ключ не нужен. Собственные методики и прогресс Learn сохраняются в localStorage браузера. Записи прохождения остаются в текущей сессии.

Зависимости node_modules и готовая сборка не включены: они создаются при установке и сборке. История Git и привязка к опубликованному сайту удалены из копии, чтобы можно было создать собственный репозиторий.

Это не чистый Vite-стартер: проект использует маршрутизацию app/ через Vinext.
